# ☕ Brew Haven

A modern, responsive coffee shop website built using **HTML5, CSS3, and Vanilla JavaScript**. Brew Haven showcases a premium café experience with a clean, mobile-first design, smooth animations, and an intuitive user interface following **2025 UI/UX** and **WCAG accessibility** principles.

---

## 🌟 Features

- 📱 Mobile-First Responsive Design
- 🎨 Modern 2025 UI/UX
- ☕ Beautiful Coffee Menu
- 🍰 Signature Desserts Section
- 👨‍🍳 About Brew Haven
- 👩‍🍳 Meet Our Baristas
- ⭐ Customer Testimonials
- ❓ Interactive FAQ Accordion
- 📧 Newsletter Subscription
- 📍 Contact Form
- 🦶 Premium Footer
- 🍔 Responsive Navigation Menu
- ✨ Smooth Scroll & Hover Animations
- ♿ Semantic HTML & Accessible Design
